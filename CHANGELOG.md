# Changelog

All notable changes to Context are recorded here.

## Unreleased

### Added

- XcodeGen project for iPhone and iPad.
- Native iOS 26 browser shell with tabs, navigation, a night-atlas home, and settings.
- Searchable local bookmarks and browsing history.
- EasyList and EasyPrivacy content protection with a per-site control.
- Reader extraction for supported article pages.
- Explicit Grok Bot handoff with editable task, assigned teammate label, readable text, copy, share, and app opening.
- Context app icon and vector mark.
- CI checks for builds, unit tests, SwiftLint, and license headers.
- MPL-2.0 repository and community files.
