# Context app icon provenance

The Context app icon and in-app mark are original project assets created for this repository on August 23, 2026.

- Vector source: `app/Resources/Assets.xcassets/ContextMark.imageset/ContextMark.svg`
- Website copy: `site/context-mark.svg`
- Shipping raster: `app/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png`
- Authoring method: code-authored SVG using original geometric paths and gradients.
- Rasterization method: rendered locally with macOS Quick Look at 1024×1024, then flattened to an opaque PNG for Apple's app-icon requirements.
- Third-party source material: none.
- Generative-image source material: none.

The icon's white open “C” and blue page card are Context identity elements. They are not derived from the Comet, Grok, X, Cursor, or Grok Bot marks.
